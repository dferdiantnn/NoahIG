Cara Download File Data Instagram (Resmi Meta)

Metode resmi 100% aman via Meta Accounts Center.

1
Buka Pengaturan Akun Instagram Buka aplikasi Instagram → Profil → Menu Garis Tiga (kanan atas) → Pusat Akun (Accounts Center) → Informasi dan izin Anda.
2
Pilih Unduh Informasi Anda Klik Unduh informasi Anda (Download your information) → Pilih akunmu → Pilih opsi Sebagian informasi (Some of your information) → Centang Pengikut dan Mengikuti (Followers and Following).
3
PENTING: Pilih Format JSON Pada menu Format, pilih JSON (bukan HTML) dan Rentang Tanggal Sepanjang Waktu (All time). Lalu klik Kirim Permintaan.
4
Masukkan ke NoahIG Setelah file ZIP siap (cek email kedua dari Meta), download file ZIP-nya dan cukup tarik & lepas file ZIP tersebut langsung ke halaman NoahIG ini!
